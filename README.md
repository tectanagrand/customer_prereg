## Project Overview

### Backgrounds

Everytime customers request to pick up goods from company, its loading note is created manually. After the goods picked and loaded, its process logged on WB and synced to SAP. But this current process prone to some faulty since loading note created manually, goods might be picked without any valid loading note. Customer Prereg App answers this problem by integrating its system to WB and SAP so its loading note and customer requests will be validated from those system. Every loading process must be requiring loading note created from SAP.
